## Plan-time confirmations (resolved by reading code)

- MCP args schema: `MCPTool.args_schema` is a Pydantic model class (`service/mcp/toolkit.py:108,572`; empty `inputSchema` gives an empty model). Mandatory names = `{n for n, f in args_schema.model_fields.items() if f.is_required()}`; an empty model counts as "no schema" (UNVERIFIED).
- Placeholder syntax: Jinja2 `Template(...).render(context)` with default `Undefined`. A missing plain name renders empty; a missing dotted root can cause raw-template fallback. Parse with the runtime's environment settings, track the scope of each occurrence, and collect only supported free plain/dotted output references. Do not import the service renderer into `contracts/`.
- Resolver lifecycle: created before the resource stage as a recorder; its built-in lookup is enabled only after the stage returned without raising; before that it answers UNKNOWN (T10).
- The corpus loader passes a `WorkflowConfigTemplate`, a sibling of `WorkflowConfig`, hence `WorkflowConfigBase` typing.
