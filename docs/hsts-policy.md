# Security Response Headers

The AI/Run API (`/code-assistant-api/*`) adds the following headers to every HTTP
response, including error and streaming responses:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
X-Content-Type-Options: nosniff
```

Both headers are set by `SecurityHeadersMiddleware` in
`src/codemie/rest_api/middleware/security_headers.py`, registered globally in
`src/codemie/rest_api/main.py`. It is implemented as a raw ASGI middleware (rather
than `BaseHTTPMiddleware`) so the headers are applied to streaming responses and to
responses generated by exception handlers.

`Strict-Transport-Security` tells browsers to ignore the header on plain-HTTP
connections, so it is safe to emit when TLS is terminated at the ingress.
Redirecting HTTP to HTTPS remains an ingress responsibility.

`X-Content-Type-Options: nosniff` stops browsers from MIME-sniffing response bodies,
so a reviewer adding or updating the ingress does not need to duplicate or add this
header there.
